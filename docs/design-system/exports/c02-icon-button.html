COMPONENT · C02 · ACTIONS
Icon button
A button with only an icon, for compact, well-known actions (notifications, close, more). Needs an accessible name. Outline in toolbars; Ghost inside other components (toast close, input suffix).
Component set
Name = Icon Button/<Style>/<Size>/<State> · private base _IconButton/Base. MD 40 × 40 = 16 icon + 2 × padding 12 (matches input height). SM 32 × 32 = 16 + 2 × icon-button.sm.padding 8 (ghost only: toast close, row actions). Instance swap: Icon. Slot-like: Badge (Notification badge, off by default).
