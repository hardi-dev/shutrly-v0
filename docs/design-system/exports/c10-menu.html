Usage
Select (menu) vs Radio: 6+ options or tight space → Select; 2–5 options with room → Radio (C06). Action menu for secondary row actions; primary action stays a visible Button.
one of 2–5, room to show → Radio
one of 6+ / tight space → Select
many of many → Multi-select (checkbox items)
row actions → Action menu (⋯)
≥ 10 options → add search Input at top (combobox, tier 2)
Accessibility
WCAG 2.1 AA (C-008).
• Select: button/combobox with aria-expanded + aria-controls → listbox. Action: button aria-haspopup=menu → role=menu.
• Opens on Enter/Space/↓; Esc closes and returns focus to the trigger; Tab closes.
• Focus stays on the trigger or moves into the list (aria-activedescendant) — never lost.
• Panel edge: border.default + shadow (non-text contrast via elevation, not colour alone).
