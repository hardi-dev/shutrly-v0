Alert
Persistent inline guidance or status beside related content. Tinted surface, status icon, title, optional body/action, and optional Close (off by default). No timer or floating shadow. Tokens: component.alert.*.
Component set
Name = Alert/<Tone> · private base _Alert/Base. Tones: success, info, warning, danger, highlight. Text: Title, Body, Action. Booleans: Body (on), Action (off), Close (off). Library specimen width 360; instances fill their content region.

Usage
Place in the page flow beside the related content or action. Use Info for verification guidance; place the resend button after the alert. No timed dismissal or floating stack.
• Don’t use Alert as the only field-level error cue; show input error state and helper text too.
• Don’t include more than one action or hide required guidance behind Close.
• Don't: rely on the tint alone — every tone has its own icon and a title that says what happened.
Accessibility
WCAG 2.1 AA (C-008).
• Static guidance stays in reading order. Use role=status for newly inserted non-urgent feedback and role=alert for urgent errors.
• Close is optional and off by default. Enable only when the message is safe to dismiss; label the button for assistive technology.
• Keep important actions available outside the Alert as well.
• Contrast: title/action status.*.fg on its .bg ≥ 4.5 : 1 (light); text.primary on the dark tint (dark).
