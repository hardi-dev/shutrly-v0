# Business Rules

### BR-BOOK-001 — Valid Stay
Check-out must occur after check-in.

### BR-BOOK-002 — Capacity
Guest count must not exceed room capacity.

### BR-BOOK-003 — No Overlap
Confirmed bookings for the same room must not overlap.

### BR-BOOK-004 — Confirmation Recheck
Availability must be revalidated when booking is created.

### BR-BOOK-005 — Server Price Authority
Final booking price must be calculated server-side.

### BR-BOOK-006 — Price Snapshot
The confirmed booking stores the final price at confirmation time.
