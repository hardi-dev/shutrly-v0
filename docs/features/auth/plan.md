# F-01 Auth & Account Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an Owner register, verify their email, sign in with a password or Google, recover or change their password, and update their display name. Every owner request is gated by account status and email verification.

**Architecture:** Better Auth 1.7.x owns identity, credentials, sessions and tokens (ADR-002). It is created per request over the request's Neon Pool (ADR-009) and hidden behind `IdentityPort`. Framework-free domain rules live in `features/auth/domain`. Use cases in `features/auth/application` orchestrate ports: identity, email outbox, rate limiter and workspace destination. Adapters implement those ports, `composition/identity.ts` wires them per request, and `app/` holds thin pages, server actions and route handlers.

**Tech Stack:** Next.js App Router on Cloudflare Workers (OpenNext) · TypeScript strict · Better Auth `1.7.6` + Drizzle adapter · Drizzle ORM · Neon `@neondatabase/serverless` Pool · Resend (HTTP API via `fetch`) · Zod 4 · React Hook Form · React Aria Components (via `src/ui` wrappers) · Tailwind CSS v4 · Vitest · Playwright + `@axe-core/playwright`.

**Source documents (read before starting any task):** [spec.md](spec.md) · [acceptance-criteria.md](acceptance-criteria.md) · [technical-design.md](technical-design.md) · [design.md](design.md) · [diagrams/](diagrams/) · [constitution](../../constitution.md) · [coding rules](../../coding-rules.md) · [ADR-013](../../architecture/decisions/ADR-013-auth-rate-limit-store.md).

## Global Constraints

- **Identity:** there is exactly one identity table, Better Auth `user`. Never create an `owner` or domain user table (BR-AUTH-002, ADR-002).
- **Authority:** the server decides everything. Client validation and `middleware.ts` are convenience only (C-004).
- **No secrets in logs:** never log passwords, tokens, cookies, verification/reset URLs, OAuth codes, Google tokens, raw provider payloads or email addresses (C-103, AC-AUTH-021). Log auth events only through `authLog`.
- **Database connections:** one Neon `Pool` per request, closed with `waitUntil(pool.end())`. Never create a module-level pool (ADR-009).
- **Shared test database:** integration tests use the single shared non-production Neon database. Every test uses `uniqueEmail()` / `uniqueIp()`, asserts only on its own rows, and never truncates or deletes other data.
- **Migrations:** generated by Drizzle, reviewed, committed, and applied only from `main` by CI. Never edit an applied migration.
- **Passwords (A-1):** 8–128 characters, measured with JavaScript `string.length` (the same measure Better Auth uses). No composition rules.
- **Sessions (A-2):** 7 days (`604800` s), sliding, refreshed at most daily (`86400` s). Cookie cache disabled.
- **Links (A-3):** verification link valid 24 h (`86400` s), reset link 1 h (`3600` s). Both are single-use, and a newer link supersedes older ones.
- **Rate limits (A-6):**
  - Login: 5 failed attempts per 15 min, counted per email and per IP separately.
  - Register, forgot password and resend verification: 3 per hour per email, 20 per hour per IP.
  - Resend button: 60 s cooldown.
- **Google:** request identity scopes only, exactly `openid email profile`. Never store Google tokens (ADR-012).
- **Naming:** files use `kebab-case`; tables and columns use `snake_case`; TypeScript uses `camelCase`; enums use `UPPER_SNAKE_CASE`. Each unit lives in its own folder with a sibling `*.test.ts(x)`.
- **Tests:** every test title starts with the `AC-AUTH-*` or `BR-AUTH-*` ID it covers.
- **Commits:** conventional commits, and each ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Verified library facts (Better Auth 1.7.6, read from the published package)

- **Verification tokens are stateless** HS256 JWTs (`api/routes/email-verification.mjs`). They are neither single-use nor superseded. Password reset tokens live in `verification` as `reset-password:<token>`, and requesting a new one does **not** delete the older ones. → This plan adds `auth_latest_link` (Task 3) and `LatestLinkRegistry` (Task 9).
- **Implicit account linking refuses an unverified local user.** The `accountLinking.requireLocalEmailVerified` default is `true` and is deprecated to become unconditional. It also skips the `email_verified` check for providers listed in `trustedProviders`. This plan therefore:
  - keeps `trustedProviders` **empty**, so Google's `email_verified` claim is always required;
  - runs the BR-AUTH-007 takeover guard inside Google `mapProfileToUser`, which receives the ID-token claims before Better Auth looks up the local user (Task 27).
- `auth.api.*` calls accept `returnHeaders: true` and then return `{ headers, response }`. The plan reads `set-cookie` from `headers`.
- Option names used in this plan:
  - `emailAndPassword`: `enabled`, `minPasswordLength`, `maxPasswordLength`, `requireEmailVerification`, `autoSignIn`, `sendResetPassword`, `resetPasswordTokenExpiresIn`, `revokeSessionsOnPasswordReset`
  - `emailVerification`: `sendVerificationEmail`, `sendOnSignUp`, `autoSignInAfterVerification`, `expiresIn`
  - `session`: `expiresIn`, `updateAge`, `cookieCache`
  - `account`: `accountLinking`, `updateAccountOnSignIn`
  - top level: `databaseHooks`, `rateLimit`
  - `advanced.ipAddress.ipAddressHeaders`
- The CLI package is `auth` (`npx auth@1.7.6 generate`). `@better-auth/cli` is frozen at 1.4.

```ts
// src/features/auth/domain/credentials/credentials.ts
export type NormalisedEmail = string & { readonly __brand: "NormalisedEmail" };

export const PASSWORD_MIN_LENGTH = 8;
export const PASSWORD_MAX_LENGTH = 128;
export const DISPLAY_NAME_MAX_LENGTH = 100;

export function normaliseEmail(raw: string): NormalisedEmail {
  return raw.trim().toLowerCase() as NormalisedEmail;
}

export type PasswordCheck = "OK" | "TOO_SHORT" | "TOO_LONG";

// Uses string.length (UTF-16 units) to match Better Auth's own length check.
export function checkPassword(password: string): PasswordCheck {
  if (password.length < PASSWORD_MIN_LENGTH) return "TOO_SHORT";
  if (password.length > PASSWORD_MAX_LENGTH) return "TOO_LONG";
  return "OK";
}
```

```ts
// src/features/auth/domain/account/account.ts
import {
  ACCOUNT_STATUSES,
  type AccessDecision,
  type AccountRecord,
  type AccountStatus,
  type AuthUserId,
  type GoogleLinkDecision,
} from "./account.types";

export * from "./account.types";

// Better Auth user IDs are opaque strings (ADR-002); this only brands them.
export function asAuthUserId(raw: string): AuthUserId {
  return raw as AuthUserId;
}

export function isAccountStatus(value: string): value is AccountStatus {
  return (ACCOUNT_STATUSES as readonly string[]).includes(value);
}

// Status is checked before verification (BR-AUTH-005, then BR-AUTH-003), as in diagrams/state.md.
export function accessDecision(
  account: Pick<AccountRecord, "status" | "emailVerified"> | null,
): AccessDecision {
  if (!account) return "ANONYMOUS";
  if (account.status !== "ACTIVE") return "UNAVAILABLE";
  if (!account.emailVerified) return "RESTRICTED";
  return "OWNER";
}

export function googleLinkDecision(input: {
  googleEmailVerified: boolean;
  existing: Pick<AccountRecord, "emailVerified"> | null;
}): GoogleLinkDecision {
  if (!input.googleEmailVerified) return "REJECT";
  if (!input.existing) return "CREATE";
  return input.existing.emailVerified ? "LINK" : "LINK_WITH_TAKEOVER_GUARD";
}
```

```ts
// src/adapters/auth/better-auth/create-auth.ts
import { betterAuth } from "better-auth";
import { drizzleAdapter } from "better-auth/adapters/drizzle";
import type { Db } from "@/adapters/db/client";
import * as schema from "@/adapters/db/schema/auth";

export interface AuthEnv {
  BETTER_AUTH_SECRET: string;
  BETTER_AUTH_URL: string;
  GOOGLE_CLIENT_ID: string;
  GOOGLE_CLIENT_SECRET: string;
}

export const AUTH_TTL = {
  sessionSeconds: 60 * 60 * 24 * 7,
  sessionUpdateAgeSeconds: 60 * 60 * 24,
  verifySeconds: 60 * 60 * 24,
  resetSeconds: 60 * 60,
} as const;

export interface TokenIssued {
  kind: "VERIFY_EMAIL" | "RESET_PASSWORD";
  user: { id: string; email: string; name: string };
  token: string;
}

export interface CreateAuthDeps {
  db: Db;
  env: AuthEnv;
  onToken(issued: TokenIssued): Promise<void>;
  onGoogleClaims?(claims: Record<string, unknown>): Promise<void>;
}

// Built per request: ADR-009 forbids sharing the Pool behind `db` across requests.
export function createAuth(deps: CreateAuthDeps) {
  const { db, env, onToken } = deps;
  return betterAuth({
    secret: env.BETTER_AUTH_SECRET,
    baseURL: env.BETTER_AUTH_URL,
    database: drizzleAdapter(db, { provider: "pg", schema }),
    // Auth limits are enforced by the application RateLimiter (ADR-013).
    rateLimit: { enabled: false },
    advanced: { ipAddress: { ipAddressHeaders: ["cf-connecting-ip"] } },
    user: {
      additionalFields: {
        status: { type: "string", required: false, defaultValue: "ACTIVE", input: false },
        emailVerifiedAt: { type: "date", required: false, input: false },
      },
    },
    session: {
      expiresIn: AUTH_TTL.sessionSeconds,
      updateAge: AUTH_TTL.sessionUpdateAgeSeconds,
      // Status must be read from the database on every request (AC-AUTH-014).
      cookieCache: { enabled: false },
    },
    emailAndPassword: {
      enabled: true,
      minPasswordLength: 8,
      maxPasswordLength: 128,
      // Unverified users get a restricted session instead (BR-AUTH-003, AC-AUTH-009).
      requireEmailVerification: false,
      autoSignIn: false,
      resetPasswordTokenExpiresIn: AUTH_TTL.resetSeconds,
      revokeSessionsOnPasswordReset: true,
      sendResetPassword: async ({ user, token }) =>
        onToken({ kind: "RESET_PASSWORD", user: pickUser(user), token }),
    },
    emailVerification: {
      sendOnSignUp: false,
      autoSignInAfterVerification: true,
      expiresIn: AUTH_TTL.verifySeconds,
      sendVerificationEmail: async ({ user, token }) =>
        onToken({ kind: "VERIFY_EMAIL", user: pickUser(user), token }),
    },
    databaseHooks: {
      user: {
        create: {
          before: async (data) => ({
            data: { ...data, emailVerifiedAt: data.emailVerified ? new Date() : null },
          }),
        },
        update: {
          before: async (data) =>
            data.emailVerified === true && !data.emailVerifiedAt
              ? { data: { ...data, emailVerifiedAt: new Date() } }
              : undefined,
        },
      },
    },
  });
}

export type Auth = ReturnType<typeof createAuth>;

function pickUser(user: { id: string; email: string; name: string }) {
  return { id: user.id, email: user.email, name: user.name };
}
```

```ts
import { and, count, eq, sql } from "drizzle-orm";
import type { Db } from "@/adapters/db/client";
import { account, session, user } from "@/adapters/db/schema/auth";
import {
  asAuthUserId, isAccountStatus, type AccountRecord, type AccountStatus, type AuthUserId,
} from "@/features/auth/domain/account/account";
import type { NormalisedEmail } from "@/features/auth/domain/credentials/credentials";

const CREDENTIAL = "credential";

export function createAccountStore(db: Db) {
  async function load(where: ReturnType<typeof eq>): Promise<AccountRecord | null> {
    const [row] = await db
      .select({
        id: user.id,
        email: user.email,
        name: user.name,
        status: user.status,
        emailVerified: user.emailVerified,
        hasPassword: sql<boolean>`exists (select 1 from ${account} where ${account.userId} = ${user.id} and ${account.providerId} = ${CREDENTIAL})`,
      })
      .from(user)
      .where(where)
      .limit(1);
    if (!row) return null;
    if (!isAccountStatus(row.status)) throw new Error(`user ${row.id} has invalid status`);
    return {
      id: asAuthUserId(row.id),
      email: row.email as NormalisedEmail,
      name: row.name,
      status: row.status,
      emailVerified: row.emailVerified,
      hasPassword: row.hasPassword,
    };
  }

  return {
    findByEmail: (email: NormalisedEmail) => load(eq(sql`lower(${user.email})`, email)),
    getById: (id: AuthUserId) => load(eq(user.id, id)),

    // BR-AUTH-005: status change and revocation commit together.
    async setStatusAndRevokeSessions(id: AuthUserId, status: AccountStatus) {
      await db.transaction(async (tx) => {
        await tx.update(user).set({ status, updatedAt: new Date() }).where(eq(user.id, id));
        await tx.delete(session).where(eq(session.userId, id));
      });
    },

    async revokeAllSessions(id: AuthUserId) {
      await db.delete(session).where(eq(session.userId, id));
    },

    // BR-AUTH-007: whoever pre-registered this email loses access before Google links.
    async applyGoogleTakeoverGuard(id: AuthUserId) {
      await db.transaction(async (tx) => {
        await tx
          .update(user)
          .set({ emailVerified: true, emailVerifiedAt: new Date(), updatedAt: new Date() })
          .where(eq(user.id, id));
        await tx.delete(account).where(and(eq(account.userId, id), eq(account.providerId, CREDENTIAL)));
        await tx.delete(session).where(eq(session.userId, id));
      });
    },

    async countSessions(id: AuthUserId) {
      const [row] = await db.select({ n: count() }).from(session).where(eq(session.userId, id));
      return row?.n ?? 0;
    },
  };
}

export type AccountStore = ReturnType<typeof createAccountStore>;
```

```ts
import type { z } from "zod";
import { DomainError } from "@/shared/errors/domain-error";

export const AUTH_ERROR_CODES = [
  "VALIDATION_FAILED",
  "INVALID_CREDENTIALS",
  "RATE_LIMITED",
  "EMAIL_UNVERIFIED",
  "ACCOUNT_UNAVAILABLE",
  "AUTH_REQUIRED",
  "INVALID_LINK",
  "WRONG_CURRENT_PASSWORD",
  "GOOGLE_CANCELLED",
  "GOOGLE_FAILED",
  "EMAIL_DELIVERY_FAILED",
] as const;
export type AuthErrorCode = (typeof AUTH_ERROR_CODES)[number];

// Message keys, translated by features/auth/ui/copy (Task 12). Schemas use these as Zod messages.
export type FieldErrorKey =
  | "name.required"
  | "name.tooLong"
  | "email.invalid"
  | "password.length"
  | "password.mismatch"
  | "password.wrongCurrent";

export class AuthError extends DomainError {
  constructor(readonly code: AuthErrorCode) {
    super(code);
    this.name = "AuthError";
  }
}

export interface AuthFailure {
  ok: false;
  code: AuthErrorCode;
  fieldErrors?: Record<string, FieldErrorKey>;
}

export type AuthResult<T extends object = object> = ({ ok: true } & T) | AuthFailure;

export function failure(code: AuthErrorCode, fieldErrors?: Record<string, FieldErrorKey>): AuthFailure {
  return fieldErrors ? { ok: false, code, fieldErrors } : { ok: false, code };
}

export function validationFailure(error: z.ZodError): AuthFailure {
  const fieldErrors: Record<string, FieldErrorKey> = {};
  for (const issue of error.issues) {
    const field = String(issue.path[0] ?? "form");
    fieldErrors[field] ??= issue.message as FieldErrorKey;
  }
  return failure("VALIDATION_FAILED", fieldErrors);
}
```

```ts
// src/features/auth/application/testing/in-memory-rate-limiter.ts
import type { RateLimiter, RateLimitRule } from "../ports/rate-limiter/rate-limiter.port";

export class InMemoryRateLimiter implements RateLimiter {
  private readonly counts = new Map<string, number>();

  constructor(private readonly now: () => number = () => Date.now()) {}

  private slot(key: string, rule: RateLimitRule) {
    const window = Math.floor(this.now() / (rule.windowSeconds * 1000));
    return `${key}@${window}`;
  }

  async peek(key: string, rule: RateLimitRule) {
    return (this.counts.get(this.slot(key, rule)) ?? 0) < rule.limit;
  }

  async hit(key: string, rule: RateLimitRule) {
    const slot = this.slot(key, rule);
    const next = (this.counts.get(slot) ?? 0) + 1;
    this.counts.set(slot, next);
    return next <= rule.limit;
  }

  keys(): string[] {
    return [...this.counts.keys()];
  }
}
```

```ts
// src/features/auth/application/link-outbox/link-outbox.ts
import type { AuthEmailSender, AuthLink } from "../ports/auth-email/auth-email.port";
import { authLog } from "../logging/auth-log";

// Collects links produced during a request; the use case decides whether to await delivery
// (resend, SPEC GAP-4) or send in the background (register, forgot password; ADR-011).
export class LinkOutbox {
  private readonly pending: AuthLink[] = [];

  constructor(
    private readonly sender: AuthEmailSender,
    private readonly requestId: string,
  ) {}

  enqueue(link: AuthLink): void {
    this.pending.push(link);
  }

  get pendingCount(): number {
    return this.pending.length;
  }

  async flush(): Promise<"SENT" | "FAILED"> {
    const links = this.pending.splice(0);
    const results = await Promise.allSettled(links.map((link) => this.sender.send(link)));
    let failed = false;
    results.forEach((result, i) => {
      if (result.status === "rejected") {
        failed = true;
        authLog(
          { operation: "email-send", outcome: "DELIVERY_FAILED", requestId: this.requestId, detail: links[i]?.kind },
          "error",
        );
      }
    });
    return failed ? "FAILED" : "SENT";
  }

  flushInBackground(waitUntil: (promise: Promise<unknown>) => void): void {
    if (this.pending.length === 0) return;
    waitUntil(this.flush());
  }
}
```

```ts
// Web Crypto: available on Cloudflare Workers and Node 20+.
export async function sha256Hex(value: string): Promise<string> {
  const digest = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(value));
  return [...new Uint8Array(digest)].map((b) => b.toString(16).padStart(2, "0")).join("");
}
```

```ts
// src/features/auth/application/rate-limits/auth-rate-limits.ts
import { sha256Hex } from "@/shared/crypto/sha256-hex";
import type { NormalisedEmail } from "@/features/auth/domain/credentials/credentials";
import type { RateLimiter, RateLimitRule } from "../ports/rate-limiter/rate-limiter.port";

// Spec A-6.
export const AUTH_RATE_RULES = {
  LOGIN_FAILURE: { limit: 5, windowSeconds: 15 * 60 },
  PER_EMAIL: { limit: 3, windowSeconds: 60 * 60 },
  PER_IP: { limit: 20, windowSeconds: 60 * 60 },
} as const satisfies Record<string, RateLimitRule>;

export type LimitedAction = "REGISTER" | "FORGOT_PASSWORD" | "RESEND_VERIFICATION";

const emailKey = async (scope: string, email: NormalisedEmail) => `${scope}:email:${await sha256Hex(email)}`;
const ipKey = (scope: string, ip: string) => `${scope}:ip:${ip}`;

export async function allowLimitedAction(
  limiter: RateLimiter,
  action: LimitedAction,
  email: NormalisedEmail,
  ip: string,
): Promise<boolean> {
  const [byEmail, byIp] = await Promise.all([
    limiter.hit(await emailKey(action, email), AUTH_RATE_RULES.PER_EMAIL),
    limiter.hit(ipKey(action, ip), AUTH_RATE_RULES.PER_IP),
  ]);
  return byEmail && byIp;
}

export async function isLoginBlocked(limiter: RateLimiter, email: NormalisedEmail, ip: string): Promise<boolean> {
  const [byEmail, byIp] = await Promise.all([
    limiter.peek(await emailKey("LOGIN_FAILURE", email), AUTH_RATE_RULES.LOGIN_FAILURE),
    limiter.peek(ipKey("LOGIN_FAILURE", ip), AUTH_RATE_RULES.LOGIN_FAILURE),
  ]);
  return !(byEmail && byIp);
}

export async function recordLoginFailure(limiter: RateLimiter, email: NormalisedEmail, ip: string): Promise<void> {
  await Promise.all([
    limiter.hit(await emailKey("LOGIN_FAILURE", email), AUTH_RATE_RULES.LOGIN_FAILURE),
    limiter.hit(ipKey("LOGIN_FAILURE", ip), AUTH_RATE_RULES.LOGIN_FAILURE),
  ]);
}
```

```ts
// src/adapters/rate-limit/neon-rate-limiter/neon-rate-limiter.ts
import { and, eq, lt, sql } from "drizzle-orm";
import type { Db } from "@/adapters/db/client";
import { authRateLimit } from "@/adapters/db/schema/auth";
import type { RateLimiter, RateLimitRule } from "@/features/auth/application/ports/rate-limiter/rate-limiter.port";

export function createNeonRateLimiter(db: Db, now: () => Date = () => new Date()) {
  const windowStart = (rule: RateLimitRule) => {
    const size = rule.windowSeconds * 1000;
    return new Date(Math.floor(now().getTime() / size) * size);
  };

  const limiter: RateLimiter & { purgeBefore(cutoff: Date): Promise<number> } = {
    async peek(key, rule) {
      const [row] = await db
        .select({ count: authRateLimit.count })
        .from(authRateLimit)
        .where(and(eq(authRateLimit.key, key), eq(authRateLimit.windowStart, windowStart(rule))));
      return (row?.count ?? 0) < rule.limit;
    },

    async hit(key, rule) {
      const [row] = await db
        .insert(authRateLimit)
        .values({ key, windowStart: windowStart(rule), count: 1 })
        .onConflictDoUpdate({
          target: [authRateLimit.key, authRateLimit.windowStart],
          set: { count: sql`${authRateLimit.count} + 1` },
        })
        .returning({ count: authRateLimit.count });
      // An upsert with RETURNING always yields exactly one row.
      return row!.count <= rule.limit;
    },

    async purgeBefore(cutoff) {
      const rows = await db
        .delete(authRateLimit)
        .where(lt(authRateLimit.windowStart, cutoff))
        .returning({ key: authRateLimit.key });
      return rows.length;
    },
  };
  return limiter;
}
```

```ts
const escapeHtml = (value: string) =>
  value.replace(/[&<>"']/g, (c) => ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" })[c]!);

const CONTENT = {
  VERIFY_EMAIL: {
    subject: "Verify your email for Shutrly",
    intro: "Confirm your email to finish setting up Shutrly.",
    action: "Verify email",
    expiry: "This link expires in 24 hours and works once.",
    ignore: "If you didn't create a Shutrly account, you can ignore this email.",
  },
  RESET_PASSWORD: {
    subject: "Reset your Shutrly password",
    intro: "Choose a new password for your Shutrly account.",
    action: "Choose a new password",
    expiry: "This link expires in one hour and works once.",
    ignore: "If you didn't ask for this, ignore this email. Your password stays the same.",
  },
} as const;

export function renderAuthEmail(link: AuthLink): { subject: string; text: string; html: string } {
  const c = CONTENT[link.kind];
  const text = [`Hi ${link.name},`, "", c.intro, link.url, "", c.expiry, c.ignore].join("\n");

    `<p>${c.expiry}</p>`,
    `<p>${c.ignore}</p>`,
  ].join("");
  return { subject: c.subject, text, html };
```

```ts
import {
  EmailDeliveryError, type AuthEmailSender, type AuthLink,
} from "@/features/auth/application/ports/auth-email/auth-email.port";
import { renderAuthEmail } from "./auth-email-templates";

export function createResendAuthEmailSender(config: {
  apiKey: string;
  from: string;
  fetch?: typeof fetch;
}): AuthEmailSender {
  const doFetch = config.fetch ?? fetch;
  return {
    async send(link: AuthLink) {
      const mail = renderAuthEmail(link);
      let response: Response;
      try {
        response = await doFetch("https://api.resend.com/emails", {
          method: "POST",
          headers: { Authorization: `Bearer ${config.apiKey}`, "Content-Type": "application/json" },
          body: JSON.stringify({ from: config.from, to: [link.to], subject: mail.subject, text: mail.text, html: mail.html }),
        });
      } catch {
        // The cause is dropped on purpose: it may echo request details (C-103).
        throw new EmailDeliveryError(link.kind);
      }
      if (!response.ok) throw new EmailDeliveryError(link.kind, response.status);
    },
  };
}
```

```ts
// src/adapters/auth/better-auth/latest-link-registry.ts
import { and, eq, gt } from "drizzle-orm";
import type { Db } from "@/adapters/db/client";
import { authLatestLink, type LinkPurpose } from "@/adapters/db/schema/auth";
import { sha256Hex } from "@/shared/crypto/sha256-hex";

// Better Auth 1.7 verification JWTs are reusable and older reset tokens stay valid (R-2).
// Only the latest link per user and purpose is accepted, and only once (A-3).
export function createLatestLinkRegistry(db: Db, now: () => Date = () => new Date()) {
  return {
    async record(input: { userId: string; purpose: LinkPurpose; token: string; ttlSeconds: number }) {
      const tokenHash = await sha256Hex(input.token);
      const expiresAt = new Date(now().getTime() + input.ttlSeconds * 1000);
      await db
        .insert(authLatestLink)
        .values({ userId: input.userId, purpose: input.purpose, tokenHash, expiresAt, createdAt: now() })
        .onConflictDoUpdate({
          target: [authLatestLink.userId, authLatestLink.purpose],
          set: { tokenHash, expiresAt, createdAt: now() },
        });
    },

    // Single statement, so two concurrent clicks cannot both succeed.
    async consume(purpose: LinkPurpose, token: string): Promise<string | null> {
      const rows = await db
        .delete(authLatestLink)
        .where(
          and(
            eq(authLatestLink.purpose, purpose),
            eq(authLatestLink.tokenHash, await sha256Hex(token)),
            gt(authLatestLink.expiresAt, now()),
          ),
        )
        .returning({ userId: authLatestLink.userId });
      return rows[0]?.userId ?? null;
    },

    async isCurrent(purpose: LinkPurpose, token: string): Promise<boolean> {
      const rows = await db
        .select({ userId: authLatestLink.userId })
        .from(authLatestLink)
        .where(
          and(
            eq(authLatestLink.purpose, purpose),
            eq(authLatestLink.tokenHash, await sha256Hex(token)),
            gt(authLatestLink.expiresAt, now()),
          ),
        )
        .limit(1);
      return rows.length === 1;
    },
  };
}
```

```ts
// src/adapters/auth/better-auth/better-auth-identity.ts
import { APIError } from "better-auth/api";
import type { Db } from "@/adapters/db/client";
import type { AuthLink } from "@/features/auth/application/ports/auth-email/auth-email.port";
import type { IdentityPort } from "@/features/auth/application/ports/identity/identity.port";
import { asAuthUserId } from "@/features/auth/domain/account/account";
import { createAccountStore } from "./account-store";
import { AUTH_TTL, createAuth, type Auth, type AuthEnv } from "./create-auth";
import { createLatestLinkRegistry } from "./latest-link-registry";

const LINK_PATH = { VERIFY_EMAIL: "/verify/confirm", RESET_PASSWORD: "/reset-password" } as const;
const LINK_TTL = { VERIFY_EMAIL: AUTH_TTL.verifySeconds, RESET_PASSWORD: AUTH_TTL.resetSeconds } as const;

// Expected Better Auth refusals (bad password, bad token, no session) become `{ ok: false }`;
// anything else is unexpected and propagates.
async function attempt<T>(run: () => Promise<T>): Promise<T | null> {
  try {
    return await run();
  } catch (error) {
    if (error instanceof APIError) return null;
    throw error;
  }
}

export function createBetterAuthIdentity(deps: { db: Db; env: AuthEnv; onLink(link: AuthLink): void }): {
  identity: IdentityPort;
  handler(request: Request): Promise<Response>;
  auth: Auth;
} {
  const store = createAccountStore(deps.db);
  const links = createLatestLinkRegistry(deps.db);
  const auth = createAuth({
    db: deps.db,
    env: deps.env,
    onToken: async ({ kind, user, token }) => {
      await links.record({ userId: user.id, purpose: kind, token, ttlSeconds: LINK_TTL[kind] });
      const url = `${deps.env.BETTER_AUTH_URL}${LINK_PATH[kind]}?token=${encodeURIComponent(token)}`;
      deps.onLink({ kind, to: user.email, name: user.name, url });
    },
  });

  const identity: IdentityPort = {
    findByEmail: (email) => store.findByEmail(email),
    getById: (id) => store.getById(id),

    async getSessionUserId(headers) {
      const session = await auth.api.getSession({ headers });
      return session ? asAuthUserId(session.user.id) : null;
    },

    async createPasswordUser({ name, email, password }) {
      const result = await attempt(() => auth.api.signUpEmail({ body: { name, email, password } }));
      if (!result) return { created: false };
      // With autoSignIn off, Better Auth answers an existing email with a synthetic user; check the row.
      return { created: (await store.getById(asAuthUserId(result.user.id))) !== null };
    },

    async sendVerificationLink(email) {
      await auth.api.sendVerificationEmail({ body: { email } });
    },

    async verifyEmail(token) {
      const userId = await links.consume("VERIFY_EMAIL", token);
      if (!userId) return { ok: false };
      const result = await attempt(() => auth.api.verifyEmail({ query: { token }, returnHeaders: true }));
      if (!result) return { ok: false };
      return { ok: true, userId: asAuthUserId(userId), setCookies: result.headers.getSetCookie() };
    },

    async signInWithPassword({ email, password }, headers) {
      const result = await attempt(() =>
        auth.api.signInEmail({ body: { email, password }, headers, returnHeaders: true }),
      );
      if (!result) return { ok: false };
      return { ok: true, userId: asAuthUserId(result.response.user.id), setCookies: result.headers.getSetCookie() };
    },

    async signOut(headers) {
      const result = await attempt(() => auth.api.signOut({ headers, returnHeaders: true }));
      return { setCookies: result ? result.headers.getSetCookie() : [] };
    },

    revokeAllSessions: (id) => store.revokeAllSessions(id),

    async sendResetLink(email) {
      await auth.api.requestPasswordReset({ body: { email } });
    },

    isResetLinkUsable: (token) => links.isCurrent("RESET_PASSWORD", token),

    async resetPassword({ token, newPassword }) {
      const userId = await links.consume("RESET_PASSWORD", token);
      if (!userId) return { ok: false };
      const result = await attempt(() => auth.api.resetPassword({ body: { token, newPassword } }));
      return { ok: result !== null };
    },

    async changePassword({ currentPassword, newPassword }, headers) {
      const result = await attempt(() =>
        auth.api.changePassword({
          body: { currentPassword, newPassword, revokeOtherSessions: true },
          headers,
          returnHeaders: true,
        }),
      );
      if (!result) return { ok: false };
      return { ok: true, setCookies: result.headers.getSetCookie() };
    },

    async updateName(name, headers) {
      await auth.api.updateUser({ body: { name }, headers });
    },

    async googleSignInUrl({ callbackURL, errorCallbackURL }) {
      const { headers, response } = await auth.api.signInSocial({
        body: { provider: "google", callbackURL, errorCallbackURL, disableRedirect: true },
        returnHeaders: true,
      });
      if (!response.url) throw new Error("Better Auth returned no Google authorization URL");
      return { url: response.url, setCookies: headers.getSetCookie() };
    },
  };

  return { identity, handler: (request) => auth.handler(request), auth };
}
```

```ts
// src/app/_auth/set-cookies.ts
import { cookies } from "next/headers";

export interface ParsedCookie {
  name: string;
  value: string;
  path?: string;
  maxAge?: number;
  expires?: Date;
  httpOnly?: boolean;
  secure?: boolean;
  sameSite?: "lax" | "strict" | "none";
}

export function parseSetCookie(raw: string): ParsedCookie {
  const [pair = "", ...attributes] = raw.split(";").map((part) => part.trim());
  const eq = pair.indexOf("=");
  const cookie: ParsedCookie = { name: pair.slice(0, eq), value: pair.slice(eq + 1) };
  for (const attribute of attributes) {
    const [key = "", value = ""] = attribute.split("=");
    switch (key.toLowerCase()) {
      case "path": cookie.path = value; break;
      case "max-age": cookie.maxAge = Number(value); break;
      case "expires": cookie.expires = new Date(value); break;
      case "httponly": cookie.httpOnly = true; break;
      case "secure": cookie.secure = true; break;
      case "samesite": cookie.sameSite = value.toLowerCase() as ParsedCookie["sameSite"]; break;
    }
  }
  return cookie;
}

export async function applySetCookies(setCookies: string[]): Promise<void> {
  const jar = await cookies();
  for (const raw of setCookies) jar.set(parseSetCookie(raw));
}
```

```ts
import { createDb } from "@/adapters/db/client";
import { createBetterAuthIdentity } from "@/adapters/auth/better-auth/better-auth-identity";

import type { AuthDeps, RequestMeta } from "@/features/auth/application/auth-deps";
import type { WorkspaceDestinationPort } from "@/features/auth/application/ports/workspace-destination/workspace-destination.port";
import { getRequestContext } from "./request-context";

export interface AuthScope extends AuthDeps {
  meta: RequestMeta;
  /** Secret for app-level signed cookies (pending-email cookie). */
  secret: string;
  handler(request: Request): Promise<Response>;
}

// F-02 replaces this with the real resolver (SPEC GAP-2).
const onboardingUntilWorkspaceExists: WorkspaceDestinationPort = { resolve: async () => "ONBOARDING" };

// One Pool per request, closed after the response (ADR-009).
export async function withAuthScope<T>(fn: (scope: AuthScope) => Promise<T>): Promise<T> {
  const rc = await getRequestContext();
  const { db, pool } = createDb(rc.env.DATABASE_URL);
  const outbox = new LinkOutbox(
    createResendAuthEmailSender({ apiKey: rc.env.RESEND_API_KEY, from: rc.env.AUTH_EMAIL_FROM }),
    rc.requestId,
  );
  const { identity, handler } = createBetterAuthIdentity({ db, env: rc.env, onLink: (link) => outbox.enqueue(link) });
  const scope: AuthScope = {
    identity,
    rateLimiter: createNeonRateLimiter(db),
    outbox,
    destination: onboardingUntilWorkspaceExists,
    waitUntil: rc.waitUntil,
    requestId: rc.requestId,
    meta: { ip: rc.ip, headers: rc.headers },
    secret: rc.env.BETTER_AUTH_SECRET,
    handler,
  };
  try {
    return await fn(scope);
  } finally {
    rc.waitUntil(pool.end());
  }
}
```

```tsx
// src/ui/patterns/alert/alert.tsx
import { forwardRef } from "react";

export type AlertTone = "info" | "danger";

export interface AlertProps {
  tone: AlertTone;
  title: string;
  body?: string;
  /** True when inserted as feedback (role=alert/status); false for static guidance. */
  live?: boolean;
  className?: string;
}

const ICON_PATH: Record<AlertTone, string> = {
  info: "M8 1.5a6.5 6.5 0 1 0 0 13 6.5 6.5 0 0 0 0-13ZM8 7v4M8 5h.01",
  danger: "M8 1.5a6.5 6.5 0 1 0 0 13 6.5 6.5 0 0 0 0-13ZM8 4.5V8.5M8 11h.01",
};

export const Alert = forwardRef<HTMLDivElement, AlertProps>(function Alert(
  { tone, title, body, live = false, className = "" },
  ref,
) {
  const role = live ? (tone === "danger" ? "alert" : "status") : undefined;
  return (
    <div
      ref={ref}
      role={role}
      tabIndex={-1}
      data-tone={tone}
      className={`flex w-full items-start gap-(--component-alert-gap) rounded-(--component-alert-radius) border px-(--component-alert-padding-x) py-(--component-alert-padding-y) outline-none ${className}`}
      style={{
        background: `var(--component-alert-${tone}-background)`,
        borderColor: `var(--component-alert-${tone}-border)`,
      }}
    >
      <svg
        aria-hidden="true"
        width="16"
        height="16"
        viewBox="0 0 16 16"
        fill="none"
        stroke={`var(--component-alert-${tone}-icon)`}
        strokeWidth="1.5"
        strokeLinecap="round"
        className="mt-0.5 shrink-0"
      >
        <path d={ICON_PATH[tone]} />
      </svg>
      <div className="flex min-w-0 flex-col gap-(--component-alert-text-gap)">
        <p
          className="text-(length:--font-size-body-sm) font-semibold"
          style={{ color: `var(--component-alert-${tone}-title)` }}
        >
          {title}
        </p>
        {body ? (
          <p className="text-(length:--font-size-label)" style={{ color: "var(--component-alert-body)" }}>
            {body}
          </p>
        ) : null}
      </div>
    </div>
  );
});
```

```tsx
// src/features/auth/ui/editorial-panel/editorial-panel.tsx
import { authCopy } from "../copy/auth-copy";
import { EDITORIAL_PHOTOS } from "./editorial-photos";

const TILE = 170;
const PITCH = 198;
const COLS = 7;
const ROWS = 8;
const PHOTO_CELLS = ["2:2", "3:1", "3:3", "4:0", "4:2", "5:1", "6:2"];
const LIME_CELLS = ["3:2", "6:3"];

export function tileKind(col: number, row: number): "photo" | "lime" | "mark" {
  const cell = `${col}:${row}`;
  if (LIME_CELLS.includes(cell)) return "lime";
  if (PHOTO_CELLS.includes(cell)) return "photo";
  return "mark";
}

function Mark({ color }: { color: string }) {
  return (
    <svg aria-hidden="true" width="56" height="56" viewBox="0 0 24 24" fill="none" stroke={color} strokeWidth="1.5">
      <circle cx="12" cy="12" r="9" />
      <path d="M12 3l3.5 6M21 12h-7M16.5 19.8L13 14M7.5 19.8L11 14M3 12h7M8.5 4.2L12 10" />
    </svg>
  );
}

export function EditorialPanel({ photos = EDITORIAL_PHOTOS }: { photos?: readonly string[] }) {
  const tiles = [];
  for (let col = 0; col < COLS; col++) {
    for (let row = 0; row < ROWS; row++) {
      const kind = tileKind(col, row);
      const photo = kind === "photo" ? photos[PHOTO_CELLS.indexOf(`${col}:${row}`)] : undefined;
      const style = { left: col * PITCH, top: row * PITCH + (col % 2 ? PITCH / 2 : 0), width: TILE, height: TILE };
      tiles.push(
        <div
          key={`${col}:${row}`}
          className="absolute flex items-center justify-center overflow-hidden rounded-[24px]"
          style={{
            ...style,
            background:
              kind === "lime" ? "var(--color-semantic-accent-highlight)" : "var(--color-primitive-neutral-800)",
          }}
        >
          {photo ? (
            <img src={photo} alt="" loading="lazy" decoding="async" className="h-full w-full object-cover" />
          ) : (
            <Mark
              color={kind === "lime" ? "var(--color-semantic-accent-on-highlight)" : "var(--color-primitive-neutral-600)"}
            />
          )}
        </div>,
      );
    }
  }

  return (
    <aside aria-hidden="true" className="relative h-full min-h-dvh overflow-hidden bg-(--color-semantic-surface-inverse)">
      <div
        className="absolute"
        style={{ left: -300, top: -290, width: 1400, height: 1560, transform: "rotate(15deg)", transformOrigin: "0 0" }}
      >
        {tiles}
      </div>
      <div
        className="absolute inset-x-0 bottom-0 h-[420px]"
        style={{
          background:
            "linear-gradient(to bottom, transparent 0%, color-mix(in srgb, var(--color-semantic-surface-inverse) 95%, transparent) 55%, var(--color-semantic-surface-inverse) 100%)",
        }}
      />
      <div className="absolute bottom-16 left-16 flex max-w-[712px] flex-col gap-(--space-4)">
        <p className="whitespace-pre-line text-[44px] font-bold leading-[1.08] text-(--color-primitive-neutral-50)">
          {authCopy.editorial.headline}
        </p>
        <p className="max-w-[600px] text-[15px] text-(--color-primitive-neutral-400)">{authCopy.editorial.body}</p>
      </div>
    </aside>
  );
}
```

```ts
// src/app/_auth/pending-email-cookie.ts
import { cookies } from "next/headers";

// Lets the Verification pending screen resend after registration without a session (SPEC GAP-3).
export const PENDING_EMAIL_COOKIE = "shutrly_pending_email";
export const PENDING_EMAIL_TTL_SECONDS = 30 * 60;

const encoder = new TextEncoder();
const toB64url = (bytes: Uint8Array) =>
  btoa(String.fromCharCode(...bytes)).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
const fromB64url = (value: string) =>
  Uint8Array.from(atob(value.replace(/-/g, "+").replace(/_/g, "/")), (c) => c.charCodeAt(0));

async function sign(payload: string, secret: string): Promise<string> {
  const key = await crypto.subtle.importKey("raw", encoder.encode(secret), { name: "HMAC", hash: "SHA-256" }, false, ["sign"]);
  return toB64url(new Uint8Array(await crypto.subtle.sign("HMAC", key, encoder.encode(payload))));
}

function constantTimeEqual(a: string, b: string): boolean {
  if (a.length !== b.length) return false;
  let diff = 0;
  for (let i = 0; i < a.length; i++) diff |= a.charCodeAt(i) ^ b.charCodeAt(i);
  return diff === 0;
}

export async function sealPendingEmail(email: string, secret: string, now = Date.now()): Promise<string> {
  const payload = `${toB64url(encoder.encode(email))}.${now + PENDING_EMAIL_TTL_SECONDS * 1000}`;
  return `${payload}.${await sign(payload, secret)}`;
}

export async function openPendingEmail(value: string | undefined, secret: string, now = Date.now()): Promise<string | null> {
  const parts = value?.split(".");
  if (!parts || parts.length !== 3) return null;
  const [email, expires, signature] = parts as [string, string, string];
  const payload = `${email}.${expires}`;
  if (!constantTimeEqual(signature, await sign(payload, secret))) return null;
  if (!(Number(expires) > now)) return null;
  try {
    return new TextDecoder().decode(fromB64url(email));
  } catch {
    return null;
  }
}

export async function writePendingEmail(email: string, secret: string): Promise<void> {
  (await cookies()).set({
    name: PENDING_EMAIL_COOKIE,
    value: await sealPendingEmail(email, secret),
    httpOnly: true,
    secure: true,
    sameSite: "lax",
    path: "/",
    maxAge: PENDING_EMAIL_TTL_SECONDS,
  });
}

export async function readPendingEmail(secret: string): Promise<string | null> {
  return openPendingEmail((await cookies()).get(PENDING_EMAIL_COOKIE)?.value, secret);
}
```

```ts
import type { NormalisedEmail } from "@/features/auth/domain/credentials/credentials";
import type { AuthDeps, RequestMeta } from "../../auth-deps";
import { failure, type AuthResult } from "../../errors/auth-errors/auth-errors";
import { authLog } from "../../logging/auth-log";
import { allowLimitedAction } from "../../rate-limits/auth-rate-limits";

// AC-AUTH-006, 022. The subject email comes from the caller's session or pending-email cookie,
// never from free input. Delivery is awaited here so a failure can be shown (SPEC GAP-4).
export async function resendVerification(
  deps: AuthDeps,
  subject: { email: NormalisedEmail },
  meta: RequestMeta,
): Promise<AuthResult> {
  if (!(await allowLimitedAction(deps.rateLimiter, "RESEND_VERIFICATION", subject.email, meta.ip))) {
    authLog({ operation: "resend-verification", outcome: "RATE_LIMITED", requestId: deps.requestId }, "warn");
    return failure("RATE_LIMITED");
  }
  await deps.identity.sendVerificationLink(subject.email);
  if (deps.outbox.pendingCount === 0) return { ok: true };
  const delivery = await deps.outbox.flush();
  authLog({ operation: "resend-verification", outcome: delivery, requestId: deps.requestId });
  return delivery === "SENT" ? { ok: true } : failure("EMAIL_DELIVERY_FAILED");
}
```

```ts
import { accessDecision, type AuthUserId } from "@/features/auth/domain/account/account";
import type { AuthDeps } from "../../auth-deps";
import { authLog } from "../../logging/auth-log";
import { DESTINATION_PATH } from "../../ports/workspace-destination/workspace-destination.port";

export type SignInOutcome =
  | { kind: "OWNER"; path: string }
  | { kind: "RESTRICTED"; path: "/verify" }
  | { kind: "UNAVAILABLE"; path: "/account-unavailable" };

// Runs after every way of obtaining a session (password, verification link, Google).
export async function continueAfterSignIn(
  deps: Pick<AuthDeps, "identity" | "destination" | "requestId">,
  userId: AuthUserId,
): Promise<SignInOutcome> {
  const decision = accessDecision(await deps.identity.getById(userId));
  if (decision === "OWNER") {
    return { kind: "OWNER", path: DESTINATION_PATH[await deps.destination.resolve(userId)] };

  if (decision === "RESTRICTED") return { kind: "RESTRICTED", path: "/verify" };
  // BR-AUTH-005, AC-AUTH-013/031: a non-active user keeps no session.
  await deps.identity.revokeAllSessions(userId);
  authLog({ operation: "access-gate", outcome: "UNAVAILABLE", requestId: deps.requestId, userId }, "warn");
  return { kind: "UNAVAILABLE", path: "/account-unavailable" };
}
```

```tsx
// src/features/auth/ui/form-support/form-support.tsx
"use client";
import { useEffect, useRef, useState } from "react";
import { Controller, type Control, type FieldValues, type Path, type UseFormSetError } from "react-hook-form";
import { TextField } from "@/ui/primitives/text-field/text-field";
import type { AuthErrorCode, AuthFailure, FieldErrorKey } from "@/features/auth/application/errors/auth-errors/auth-errors";
import { fieldErrorText } from "../copy/auth-copy";

// Server field errors go to their fields (first one focused); anything else becomes a form-level
// Alert that receives focus (AC-AUTH-023).
export function useServerFailure<T extends FieldValues>() {
  const [formError, setFormError] = useState<AuthErrorCode | null>(null);
  const alertRef = useRef<HTMLDivElement>(null);
  useEffect(() => {
    if (formError) alertRef.current?.focus();
  }, [formError]);

  function apply(failure: AuthFailure, setError: UseFormSetError<T>) {
    const entries = Object.entries(failure.fieldErrors ?? {});
    if (failure.code === "VALIDATION_FAILED" && entries.length > 0) {
      entries.forEach(([field, key], i) =>
        setError(field as Path<T>, { type: "server", message: key }, { shouldFocus: i === 0 }),
      );
      return;
    }
    setFormError(failure.code);
  }

  return { formError, alertRef, apply, clear: () => setFormError(null) };
}

export function ControlledField<T extends FieldValues>(props: {
  control: Control<T>;
  name: Path<T>;
  label: string;
  type?: string;
  autoComplete?: string;
  placeholder?: string;
  description?: string;
}) {
  const { control, name, ...field } = props;
  return (
    <Controller
      control={control}
      name={name}
      render={({ field: f, fieldState }) => (
        <TextField
          {...field}
          name={f.name}
          value={(f.value as string | undefined) ?? ""}
          onChange={f.onChange}
          onBlur={f.onBlur}
          inputRef={f.ref}
          errorMessage={fieldState.error?.message ? fieldErrorText(fieldState.error.message as FieldErrorKey) : undefined}
        />
      )}
    />
  );
}
```

```tsx
// src/features/auth/ui/resend-verification/resend-verification.tsx
"use client";
import { useEffect, useRef, useState } from "react";
import { Button } from "@/ui/primitives/button/button";
import { Alert } from "@/ui/patterns/alert/alert";
import type { AuthErrorCode, AuthResult } from "@/features/auth/application/errors/auth-errors/auth-errors";
import { authCopy, errorText } from "../copy/auth-copy";

const COOLDOWN_SECONDS = 60; // A-6; UX only, the server limit is authoritative.

export function ResendVerification({
  action,
  label = authCopy.verifyPending.resend,
}: {
  action: () => Promise<AuthResult>;
  label?: string;
}) {
  const [secondsLeft, setSecondsLeft] = useState(0);
  const [error, setError] = useState<AuthErrorCode | null>(null);
  const [sent, setSent] = useState(false);
  const [busy, setBusy] = useState(false);
  const alertRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (secondsLeft <= 0) return;
    const timer = setTimeout(() => setSecondsLeft((s) => s - 1), 1000);
    return () => clearTimeout(timer);
  }, [secondsLeft]);

  useEffect(() => {
    if (error) alertRef.current?.focus();
  }, [error]);

  async function resend() {
    setBusy(true);
    setError(null);
    setSent(false);
    const result = await action();
    setBusy(false);
    if (result.ok) {
      setSent(true);
      setSecondsLeft(COOLDOWN_SECONDS);
    } else {
      setError(result.code);
    }
  }

  return (
    <div className="flex flex-col gap-(--space-3)">
      {error ? <Alert ref={alertRef} tone="danger" title={errorText(error)} live /> : null}
      {sent ? <Alert tone="info" title={authCopy.verifyPending.resent} live /> : null}
      <Button type="button" variant="secondary" isDisabled={busy || secondsLeft > 0} onPress={resend}>
        {label}
      </Button>
      {secondsLeft > 0 ? (
        <p className="text-(length:--font-size-body-sm) text-(--color-semantic-text-secondary)">
          {authCopy.verifyPending.cooldown(secondsLeft)}
        </p>
      ) : null}
    </div>
  );
}
```

```ts
// src/app/actions/auth/resend-verification.ts
"use server";
import { redirect } from "next/navigation";
import { withAuthScope } from "@/composition/identity";
import type { AuthResult } from "@/features/auth/application/errors/auth-errors/auth-errors";
import { resendVerification } from "@/features/auth/application/use-cases/resend-verification/resend-verification";
import { normaliseEmail } from "@/features/auth/domain/credentials/credentials";
import { readPendingEmail } from "@/app/_auth/pending-email-cookie";

export async function resendVerificationAction(): Promise<AuthResult> {
  const result = await withAuthScope(async (scope) => {
    const userId = await scope.identity.getSessionUserId(scope.meta.headers);
    const account = userId ? await scope.identity.getById(userId) : null;
    const email = account?.email ?? (await readPendingEmail(scope.secret));
    if (!email) return null;
    return resendVerification(scope, { email: normaliseEmail(email) }, scope.meta);
  });
  if (!result) redirect("/login");
  return result;
}
```

```tsx
export default async function VerifyPage({ searchParams }: { searchParams: Promise<{ state?: string }> }) {
  const { state } = await searchParams;
  const access = await withAuthScope(async (scope) => {
    const userId = await scope.identity.getSessionUserId(scope.meta.headers);
    const account = userId ? await scope.identity.getById(userId) : null;

    if (decision === "OWNER" && userId) return { redirectTo: DESTINATION_PATH[await scope.destination.resolve(userId)] };

    return { canResend };
  });

          <ResendVerification action={resendVerificationAction} label={c.action} />

          <AuthTextLink href="/login">{c.action}</AuthTextLink>
        )}
        <AuthTextLink href="/login">{c.back}</AuthTextLink>
      </>
    );

  if (!access.canResend) redirect("/login");

      <Alert tone="info" title={c.alertTitle} body={c.alertBody} />
```

```ts
import { failure, validationFailure, type AuthResult } from "../../errors/auth-errors/auth-errors";
import { authLog } from "../../logging/auth-log";
import type { SessionCookies } from "../../ports/identity/identity.port";
import { isLoginBlocked, recordLoginFailure } from "../../rate-limits/auth-rate-limits";
import { continueAfterSignIn, type SignInOutcome } from "../continue-after-sign-in/continue-after-sign-in";
import { loginOwnerSchema } from "./login-owner.schema";

// AC-AUTH-007..010, 013, 030. Order follows diagrams/sequence/login-email-password.md:
// rate limit → credentials → status → verification.
export async function loginOwner(
  deps: AuthDeps,
  input: unknown,
  meta: RequestMeta,
): Promise<AuthResult<{ outcome: SignInOutcome } & SessionCookies>> {
  const parsed = loginOwnerSchema.safeParse(input);
  if (!parsed.success) return validationFailure(parsed.error);
  const email = normaliseEmail(parsed.data.email);

  if (await isLoginBlocked(deps.rateLimiter, email, meta.ip)) {
    authLog({ operation: "login", outcome: "RATE_LIMITED", requestId: deps.requestId }, "warn");
    return failure("RATE_LIMITED");
  }

  const signedIn = await deps.identity.signInWithPassword({ email, password: parsed.data.password }, meta.headers);
  if (!signedIn.ok) {
    await recordLoginFailure(deps.rateLimiter, email, meta.ip);
    authLog({ operation: "login", outcome: "INVALID_CREDENTIALS", requestId: deps.requestId });
    return failure("INVALID_CREDENTIALS");
  }

  const outcome = await continueAfterSignIn(deps, signedIn.userId);
  authLog({ operation: "login", outcome: outcome.kind, requestId: deps.requestId, userId: signedIn.userId });
  if (outcome.kind === "UNAVAILABLE") return failure("ACCOUNT_UNAVAILABLE");
  return { ok: true, outcome, setCookies: signedIn.setCookies };
}
```

```ts
import { accessDecision, type AccessDecision, type AccountRecord } from "@/features/auth/domain/account/account";
import { AuthError } from "../../errors/auth-errors/auth-errors";
import type { IdentityPort } from "../../ports/identity/identity.port";

type SessionReader = Pick<IdentityPort, "getSessionUserId" | "getById">;

// Reads status from the database on every call (cookie cache is off), so AC-AUTH-014 holds
// even for sessions that were never revoked.
export async function resolveOwnerAccess(
  identity: SessionReader,
  headers: Headers,
): Promise<{ decision: AccessDecision; account: AccountRecord | null }> {
  const userId = await identity.getSessionUserId(headers);
  const account = userId ? await identity.getById(userId) : null;
  return { decision: accessDecision(account), account };
}

export async function requireOwner(identity: SessionReader, headers: Headers): Promise<AccountRecord> {
  const { decision, account } = await resolveOwnerAccess(identity, headers);
  if (decision === "OWNER" && account) return account;
  if (decision === "RESTRICTED") throw new AuthError("EMAIL_UNVERIFIED");
  if (decision === "UNAVAILABLE") throw new AuthError("ACCOUNT_UNAVAILABLE");
  throw new AuthError("AUTH_REQUIRED");
}
```

```ts
export function ownerRedirectFor(code: AuthErrorCode): string {
  if (code === "EMAIL_UNVERIFIED") return "/verify";
  if (code === "ACCOUNT_UNAVAILABLE") return "/account-unavailable";
  return "/login";
}

async function checkOwner(): Promise<{ account: AccountRecord } | { refused: AuthErrorCode }> {
  return withAuthScope(async (scope) => {
    try {
      return { account: await requireOwner(scope.identity, scope.meta.headers) };
    } catch (error) {
      if (error instanceof AuthError) return { refused: error.code };
      throw error;
    }
  });
}

// Call first in every owner page and owner server action (C-004).
export async function requireOwnerOrRedirect(): Promise<AccountRecord> {
  const result = await checkOwner();
  if ("refused" in result) redirect(ownerRedirectFor(result.refused));
  return result.account;
}

// Call first in every owner route handler.
export async function guardOwnerRoute(): Promise<AccountRecord | Response> {
  const result = await checkOwner();
  if ("account" in result) return result.account;
  const status = result.refused === "AUTH_REQUIRED" ? 401 : 403;
  return Response.json({ code: result.refused }, { status, headers: { "Cache-Control": "private, no-store" } });
}

// AC-AUTH-011: auth pages send signed-in owners onward.
export async function redirectIfSignedIn(): Promise<void> {
  const target = await withAuthScope(async (scope) => {
    const { decision, account } = await resolveOwnerAccess(scope.identity, scope.meta.headers);
    if (decision === "OWNER" && account) return DESTINATION_PATH[await scope.destination.resolve(account.id)];
    if (decision === "RESTRICTED") return "/verify";
    return null;
  });
  if (target) redirect(target);
}
```

```ts
// src/middleware.ts
import { NextResponse, type NextRequest } from "next/server";

// Early, cookie-presence redirect only. requireOwnerOrRedirect()/guardOwnerRoute() are the authority.
const PUBLIC_PREFIXES = [
  "/login", "/register", "/verify", "/forgot-password", "/reset-password",
  "/account-unavailable", "/auth/continue", "/api/auth",
];

export function isPublicPath(pathname: string): boolean {
  return PUBLIC_PREFIXES.some((prefix) => pathname === prefix || pathname.startsWith(`${prefix}/`));
}

export function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;
  if (isPublicPath(pathname)) return NextResponse.next();
  const hasSessionCookie = request.cookies.getAll().some((c) => c.name.endsWith("session_token"));
  if (!hasSessionCookie) return NextResponse.redirect(new URL("/login", request.url));
  return NextResponse.next();
}

export const config = {
  matcher: ["/((?!_next/|favicon.ico|auth/editorial/).*)"],
};
```

```ts
// src/features/auth/application/use-cases/request-password-reset/request-password-reset.ts
import { normaliseEmail } from "@/features/auth/domain/credentials/credentials";
import type { AuthDeps, RequestMeta } from "../../auth-deps";
import { validationFailure, type AuthResult } from "../../errors/auth-errors/auth-errors";
import { authLog } from "../../logging/auth-log";
import { allowLimitedAction } from "../../rate-limits/auth-rate-limits";
import { requestPasswordResetSchema } from "./request-password-reset.schema";

// AC-AUTH-016, 030. Always the same answer; mail only for password-backed accounts within limits.
export async function requestPasswordReset(deps: AuthDeps, input: unknown, meta: RequestMeta): Promise<AuthResult> {
  const parsed = requestPasswordResetSchema.safeParse(input);
  if (!parsed.success) return validationFailure(parsed.error);
  const email = normaliseEmail(parsed.data.email);

  if (await allowLimitedAction(deps.rateLimiter, "FORGOT_PASSWORD", email, meta.ip)) {
    const account = await deps.identity.findByEmail(email);
    if (account?.hasPassword) await deps.identity.sendResetLink(email);
    deps.outbox.flushInBackground(deps.waitUntil);
  }
  authLog({ operation: "forgot-password", outcome: "CONFIRMED", requestId: deps.requestId });
  return { ok: true };
}
```

```ts
// src/features/auth/application/use-cases/reset-password/reset-password.ts
import type { AuthDeps } from "../../auth-deps";
import { failure, validationFailure, type AuthResult } from "../../errors/auth-errors/auth-errors";
import { authLog } from "../../logging/auth-log";
import { resetPasswordSchema } from "./reset-password.schema";

// AC-AUTH-017, 018. Better Auth revokes every session on reset (revokeSessionsOnPasswordReset).
export async function resetPassword(deps: AuthDeps, input: unknown): Promise<AuthResult> {
  const parsed = resetPasswordSchema.safeParse(input);
  if (!parsed.success) return validationFailure(parsed.error);
  const result = await deps.identity.resetPassword({ token: parsed.data.token, newPassword: parsed.data.password });
  authLog({ operation: "reset-password", outcome: result.ok ? "RESET" : "INVALID_LINK", requestId: deps.requestId });
  return result.ok ? { ok: true } : failure("INVALID_LINK");
}
```

```ts
export async function changePassword(
  deps: AuthDeps,
  input: unknown,
  headers: Headers,
): Promise<AuthResult<SessionCookies>> {
  const owner = await requireOwner(deps.identity, headers);
  const parsed = changePasswordSchema.safeParse(input);
  if (!parsed.success) return validationFailure(parsed.error);
  const result = await deps.identity.changePassword(
    { currentPassword: parsed.data.currentPassword, newPassword: parsed.data.newPassword },
    headers,
  );

  return { ok: true, setCookies: result.setCookies };
```

```ts
async function guarded<T>(run: () => Promise<T>): Promise<T> {
  try {
    return await run();
  } catch (error) {
    if (error instanceof AuthError) redirect(ownerRedirectFor(error.code));
    throw error;
  }
}

export async function updateDisplayNameAction(values: UpdateDisplayNameInput): Promise<AuthFailure | void> {
  const result = await guarded(() => withAuthScope((s) => updateDisplayName(s, values, s.meta.headers)));
  if (!result.ok) return result;
}

export async function changePasswordAction(values: ChangePasswordInput): Promise<AuthFailure | void> {
  const result = await guarded(() => withAuthScope((s) => changePassword(s, values, s.meta.headers)));
  if (!result.ok) return result;
  await applySetCookies(result.setCookies);
}
```

```ts
import type { AccountStore } from "./account-store";
import { googleLinkDecision } from "@/features/auth/domain/account/account";
import { normaliseEmail } from "@/features/auth/domain/credentials/credentials";

const googleClaims = z.object({ email: z.string().min(3), email_verified: z.boolean() });

// Called from Google mapProfileToUser, before Better Auth looks up the local user (BR-AUTH-007).
export function createGoogleClaimsGuard(store: Pick<AccountStore, "findByEmail" | "applyGoogleTakeoverGuard">) {
  return async (claims: Record<string, unknown>): Promise<void> => {
    const parsed = googleClaims.safeParse(claims);
    if (!parsed.success) return;
    const existing = await store.findByEmail(normaliseEmail(parsed.data.email));
    const decision = googleLinkDecision({ googleEmailVerified: parsed.data.email_verified, existing });
    if (decision === "LINK_WITH_TAKEOVER_GUARD" && existing) await store.applyGoogleTakeoverGuard(existing.id);
  };
}

// True for Better Auth OAuth callback requests (e.g. /callback/google).
export function isSocialCallback(ctx: { path?: string } | null): boolean {
  return Boolean(ctx?.path?.startsWith("/callback/"));
}
```

```ts
import type { AuthEmailSender, AuthLink } from "@/features/auth/application/ports/auth-email/auth-email.port";

// E2E only (local `next dev`): keeps links in process memory so Playwright can open them.
const captured: AuthLink[] = [];

export function createCapturingEmailSender(): AuthEmailSender {
  return { send: async (link) => void captured.push(link) };

export function capturedLinks(to: string): AuthLink[] {
  return captured.filter((link) => link.to === to.toLowerCase());
}

export function isEmailCaptureEnabled(env: { E2E_EMAIL_CAPTURE?: string; BETTER_AUTH_URL?: string }): boolean {
  if (env.E2E_EMAIL_CAPTURE !== "1" || !env.BETTER_AUTH_URL) return false;
  const host = new URL(env.BETTER_AUTH_URL).hostname;
  return host === "localhost" || host === "127.0.0.1";
}
```
