# Features

One folder per feature **currently in discovery or development** (slug from [feature-map](../product/feature-map.md)):

```text
features/<slug>/
  spec.md                  goal, story, flows, BR refs, out of scope, open questions
  acceptance-criteria.md   AC-<AREA>-NNN
  diagrams/                activity / sequence / state — only where useful
  design.md                Pencil reference + screen/state inventory
  technical-design.md      DB/API/components/tests/iterations
  verification-report.md
```
