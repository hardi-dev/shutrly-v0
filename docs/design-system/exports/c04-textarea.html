Textarea
Multi-line text entry (Catatan untuk klien). Same states and tokens as Input; adds input.padding-y (12) because the box isn't a fixed 40 px line.

Name = Textarea/<State> · private base _Textarea/Base. Default height 96 (≈ 3 lines, documented); grows with content in code up to a max, then scrolls.
