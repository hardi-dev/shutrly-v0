App panel
The white working surface of every Owner page (legacy dashboard › Panel): a 72 px header with the page title and header actions, and a Content slot holding Page Content (layout insets 28 / 40, section gap 28, container max-width 1096 centred). Sits on surface.canvas next to the Sidebar (C29). Tokens: component.panel.app.*.
Component set
Single component. Text: Title. Slots: Actions (header, right; Input/Search, Icon Button/Outline, Button), Content (accepts Page Content; its Container slot takes the page sections). Height hugs content; in the App shell it fills the screen. Default content = empty Page Content; the dashboard (greeting + metric row) is shown in the Modes exhibit.

Usage
One App Panel per Owner page, inside the App shell (C30). Layout insets are owned by the panel (SP5): screens never add their own outer padding.
• Do: page title = the Nav item label ("Proyek"); the greeting headline replaces it only on the dashboard content.
• Do: sections stack at 28; inside sections use 16 (tiles) / 24 (columns) per board 08.
• Don't: nest a panel in a panel or add shadows (flat, §6); cards inside are Table / Metric tile with their own borders.
Accessibility
WCAG 2.1 AA (C-008).
• <main> landmark; the header title is the page <h1>; header actions live in the header, before main content in tab order.
• Search: role=searchbox + aria-keyshortcuts="Meta+K"; Notifications icon button: aria-label with the unread count.
• The content container stops at 1096 (panel.app.content.max-width) and centres on wider screens; below 1280 the sidebar collapses (future breakpoint spec).
