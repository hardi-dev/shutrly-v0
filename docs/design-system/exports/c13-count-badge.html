Count badge
Neutral number showing how many items sit behind a nav item, tab or filter (e.g. Proyek 12). Informational only — not an alert. Tokens: component.nav.count.*.
Component set
Single component, no variant axes (no base needed). Text prop: Count.
12
Content
Digits only. 0 → hide the badge (don't show "0"). ≥ 100 → "99+". No words, no icons. Hugs its number; pill keeps 1-digit counts round-ish.
