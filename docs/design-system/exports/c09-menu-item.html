Menu item
One row inside a Menu (C10): a select option, a multi-select option (with checkbox) or an action (with icon). Destructive items (Hapus proyek) use the danger role. Hover and keyboard highlight look the same.
Component set
Name = Menu Item/<Type>/<State> · private base _MenuItem/Base, width 240 (instances fill the menu). Booleans: Icon · Description · Check · Checkbox (nested C05). ~36 px high (8 + 20 + 8).

Accessibility
WCAG 2.1 AA.
• role=option (listbox) or role=menuitem / menuitemcheckbox (menu). aria-selected / aria-checked carries state — not only the check colour.
• Keyboard highlight = hover style (aria-activedescendant); Enter/Space selects; type-ahead jumps.
• Destructive items: label says what is deleted; confirm in a dialog.
• Disabled: aria-disabled, stays in the list (skipped by arrows).
