Usage
One Active item per sidebar (the current page, or its parent section). Hover and Focus are interaction states for specs and prototypes.
• Do: group rarely-used destinations at the bottom (flexible spacer pushes them down, SP7).
• Don't: use action.primary anywhere else in the sidebar — it marks "you are here".
• Don't: add a second level of nesting; use a page-level Segmented control or tabs instead.
Accessibility
WCAG 2.1 AA (C-008).
• Links inside <nav aria-label="Utama">; the Active item has aria-current=page (not colour alone: filled background).
• Count is part of the accessible name ("Proyek, 12").
• Focus: 2 px focus.ring outside + focus.glow; never removed.
• Target height 36 px (8 + 20 + 8) — fine for the owner web app (≥ 24 px).
