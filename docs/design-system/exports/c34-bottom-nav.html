Bottom nav
The Owner app’s primary navigation on phones (Owner 2026-09-26, exploration board 06 option B): Dasbor · Proyek · [+] · Klien · Lainnya. Active tab = colour only (bottom-nav.item.active: action.primary, dark status.info.fg) + bold label; the + is a raised 54 px circle with a surface.panel ring. Padding-top 12 (Owner). “Lainnya” opens Bottom Sheet/Menu (C32), which carries every other Sidebar destination. Tokens: component.bottom-nav.*.

Usage
4 destinations + 1 action. Everything else lives in “Lainnya” (Bottom Sheet/Menu).
• Tabs: Dasbor · Proyek · Klien · Lainnya (Owner). Labels are one word; the active tab = current page only.
• The CTA is the single most common create action (+ Proyek baru); it opens a Form sheet or a page — never a menu of actions.
• Badges: Notification Badge on the tab icon for counts that need attention (Proyek 12). Never a badge on the CTA.
• Hidden while the keyboard is open; stays visible on scroll (no hide-on-scroll).
Accessibility
WCAG 2.1 AA (C-008).
• <nav aria-label="Utama"> with links; the active tab has aria-current=page. The CTA is a button with aria-label “Proyek baru”.
• Targets: tabs ≥ 64 × 48, CTA 54 — above 44 px. Labels never hidden (icon + text).
• Badge count is in the accessible name (“Proyek, 12 baru”). Active state uses colour + bold weight, not colour alone.
