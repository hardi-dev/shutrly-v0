# Feature: Hotel Booking

ID: F-007
Status: READY FOR DEVELOPMENT

## Goal
Allow an authenticated guest to reserve an available room for selected dates.

## Inputs
- roomId
- checkIn
- checkOut
- guestCount

## Main Flow
1. Select dates and guests.
2. Check availability.
3. Display estimated price.
4. Review booking.
5. Confirm.
6. Recheck availability.
7. Calculate final price server-side.
8. Create booking.
9. Show confirmation.
